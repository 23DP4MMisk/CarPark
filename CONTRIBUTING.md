## Pull Request noteikumi

1. Viens PR = viena Trello kartīte.
2. PR aprakstā - saite uz kartīti.
3. Recenzents ir obligāts:
   - backend kodu recenzē frontend dalībnieks;
   - frontend kodu recenzē komandas vadītājs.
4. Pēc Approve autors pats veic merge.
